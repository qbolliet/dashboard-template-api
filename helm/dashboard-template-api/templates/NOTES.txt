Thanks for installing {{ .Chart.Name }} {{ .Chart.Version }} (app {{ .Chart.AppVersion }}).

1. Reach the API:
{{- if .Values.ingress.enabled }}
{{- range $host := .Values.ingress.hosts }}
   - https://{{ $host.host }}
{{- end }}
{{- else }}
   kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "dta.fullname" . }} 4000:{{ .Values.service.port }}
   curl http://localhost:4000/ready
{{- end }}

2. Health checks:
   /health  -> liveness
   /ready   -> readiness (DuckDB pool + Redis)
   /metrics -> operational metrics

3. Cache invalidation (admin endpoints, header `x-admin-key`):
   POST /api/cache/invalidate-all
   POST /api/cache/invalidate/<database>
   GET  /api/cache/stats

   Set ADMIN_API_KEY via secrets.data.ADMIN_API_KEY (or secrets.existingSecret).

{{- if .Values.redis.enabled }}

4. In-cluster Redis (Bitnami) is enabled. The password is auto-generated by the
   sub-chart and stored in Secret "{{ include "dta.redisAuthSecretName" . }}"
   (key "redis-password"). To recover it:
     kubectl --namespace {{ .Release.Namespace }} get secret {{ include "dta.redisAuthSecretName" . }} \
       -o jsonpath='{.data.redis-password}' | base64 -d
{{- else }}

4. External Redis: REDIS_HOST/REDIS_PORT must be set in `values.config`,
   and REDIS_PASSWORD provisioned in the application Secret.
{{- end }}

5. Verify a deployment:
   kubectl --namespace {{ .Release.Namespace }} rollout status deploy/{{ include "dta.fullname" . }}

6. Useful commands:
   helm --namespace {{ .Release.Namespace }} status {{ .Release.Name }}
   helm --namespace {{ .Release.Namespace }} upgrade {{ .Release.Name }} <chart>
   helm --namespace {{ .Release.Namespace }} rollback {{ .Release.Name }}
